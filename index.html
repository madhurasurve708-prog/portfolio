CASE STUDY 01

                        
Seva Setu

                        
Digital Civic Complaint Management Platform

                        
                        

                            

                                
01 — The Problem

                                
Traditional complaint handling can involve scattered phone calls, limited visibility into complaint status, and difficulty maintaining a clear history of issues.

                            

                            

                                
02 — The Solution

                                
Seva Setu provides a centralized platform where citizens can submit complaints, attach photos, track progress and receive updates, while officials can manage complaints based on wards, departments, categories and priority.

                            

                            

                                
03 — How I Built It & Contribution

                                
I designed and implemented the FastAPI backend, PostgreSQL database, and Supabase integration. I worked on JWT authentication, storage buckets for uploads, and overall API structure, while my sister contributed to the React Native/Expo frontend application.

                            

                        


                        
04 — Key Features

                        

                            Citizen authentication
                            Complaint creation
                            Complaint photo uploads
                            Complaint tracking
                            Ward-based management
                            Department management
                            Official dashboards
                            Complaint escalation
                            Progress updates
                            Announcement system
                        


                        
05 — Technology Stack

                        

                            FastAPI
                            Python
                            PostgreSQL
                            Supabase Storage
                            React Native
                            Expo
                            TypeScript
                            REST APIs
                            JWT Auth
                        


                        

                            
06 — Result

                            
The project evolved from a prototype into a functional civic-tech application with separate citizen and official workflows.

                    Workflow
                    
From Idea to Working Product

                    

                        A systematic 4-step development lifecycle that guarantees high quality and clear architecture.
                    

                

                
                

                    

                        STEP 01
                        
Understand

                        
Defining the project goals, functional scope, end-user flows, and core API constraints.

                    

                    
                    

                        STEP 02
                        
Plan

                        
Designing database schemas, routing paths, tech stack dependencies, and system modules.

                    

                    
                    

                        STEP 03
                        
Build

                        
Developing clean, modular backend endpoints, integrating storage modules, and styling responsive views.

                    

                    
                    

                        STEP 04
                        
Refine

                        
Conducting API route checks, debugging response objects, launching live hosts, and packaging source code.
